المنصة الرياضية - نسخة التثبيت للزوار

1) ارفع جميع الملفات والمجلدات إلى جذر GitHub Pages.
2) افتح رابط المنصة من Chrome على الهاتف.
3) استخدم خيار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4) ستظهر أيقونة المنصة الرياضية على الجهاز، ويعمل التطبيق بواجهة مستقلة ويمكنه فتح المنصة حتى عند ضعف الاتصال بعد أول زيارة.

مهم: هذه نسخة PWA وليست APK. لا تحتاج إلى متجر Google Play.
