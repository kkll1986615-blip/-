# المنصة الرياضية

نسخة جاهزة للنشر على GitHub Pages.

## الملفات
- `index.html` — المنصة الرياضية.
- `manifest.webmanifest` — إعدادات تثبيت التطبيق.
- `sw.js` — Service Worker للتحديث والتثبيت.
- `icons/` — جميع أيقونات المنصة.
- `.nojekyll` — لضمان نشر الملفات كما هي.

## النشر
1. أنشئ Repository جديد في GitHub.
2. ارفع **جميع محتويات هذا المجلد** إلى جذر الـ Repository.
3. من Settings → Pages.
4. اختر Deploy from a branch.
5. اختر Branch: `main` و Folder: `/ (root)`.
6. احفظ وانتظر اكتمال النشر.

اسم التطبيق عند التثبيت: **المنصة الرياضية**.
