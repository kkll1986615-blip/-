المنصة الرياضية — نسخة النشر السريعة

GitHub Pages:
1) أنشئ مستودعًا جديدًا أو افتح المستودع الحالي.
2) ارفع محتويات هذا المجلد كما هي إلى الجذر (index.html مع مجلد icons والملفات الأخرى).
3) فعّل Settings > Pages > Deploy from branch > main/root.

Netlify:
1) ارفع مجلد هذه النسخة إلى Netlify Drop أو اربطه بالمستودع.
2) اجعل مجلد النشر هو هذا المجلد (publish = .).

مهم: Firebase يبقى مصدر المزامنة المشتركة؛ لا تحذف بيانات Firebase عند إعادة النشر.
