المنصة الرياضية - نسخة GitHub Pages / PWA

ارفع كل الملفات والمجلد icons إلى جذر مستودع GitHub Pages.
يجب أن يكون index.html في الجذر.
بعد النشر افتح الموقع عبر HTTPS ثم أعد تحميله.
إذا كانت هناك نسخة قديمة مثبتة، احذف الاختصار القديم ثم افتح الموقع من جديد.
من Chrome اختر: ⋮ > تثبيت التطبيق، أو استخدم زر "تثبيت المنصة" الذي يظهر داخل الموقع عندما يصبح التطبيق قابلاً للتثبيت.
