# المنصة الرياضية — نسخة PWA جاهزة

ارفع الملفات كما هي مع الحفاظ على المجلدات:
- index.html
- manifest.webmanifest
- sw.js
- icons/

المهم أن تكون المنصة منشورة عبر HTTPS.
بعد الرفع افتح الموقع في Chrome، حدّث الصفحة، ثم افتح قسم «تثبيت البرنامج».
ستظهر أيقونة رياضية للمنصة بدل أيقونة Chrome.

إذا كان الموقع قديمًا في الهاتف:
1. افتح الموقع في Chrome.
2. حدّث الصفحة مرتين.
3. افتح قائمة ⋮ واختر «تثبيت التطبيق».
