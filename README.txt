المنصة الرياضية — نسخة PWA سهلة التثبيت

ارفع كل محتويات هذا المجلد إلى نفس مكان index.html في GitHub Pages أو Cloudflare Pages.

على Android/Chrome: افتح الموقع ثم اضغط «تثبيت المنصة الآن». إذا لم يظهر خيار التثبيت، افتح قائمة Chrome واختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

الملفات: index.html + manifest.webmanifest + sw.js + icons/.
هذه PWA وليست APK؛ لا تحتاج إلى Firebase CLI للتثبيت.
